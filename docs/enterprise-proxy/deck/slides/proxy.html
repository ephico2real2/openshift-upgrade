Our enterprise proxy and firewall

Enterprise proxy, highly available

  • HTTP CONNECT on TCP 443 only
  • Allowlist: the four Red Hat host groups; anything else gets 403 (C3)
  • TLS inspected and re-signed with the enterprise CA (C7)

Firewall

Only the proxy may go out. Nodes and pods have no direct route (C1).

The enterprise CA is on every node and in user-ca-bundle, which the Proxy object names in trustedCA. Red Hat: the bundle is "injected into the trust store of platform components that make egress HTTPS calls".
