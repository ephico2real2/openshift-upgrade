Live upgrade guidance: the cluster reads recommendations from api.openshift.com, including conditional-path risks, as soon as Red Hat publishes them; a local Update Service knows only what the last sync brought. Catalogs: oc-mirror v2 does not infer operator dependencies, so mirrored catalogs need each dependency listed by hand. Insights and telemetry are off unless enabled; updates do not need them. Ansible automates the upgrade in both cases, under the proxy too; what goes with the proxy approach is the manual mirror and its upkeep, which is a lot of work better spent on the update process itself.
