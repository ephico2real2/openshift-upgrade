The same update, step by step

Steps 1 to 6 are the platform's

Check for updates, verify the release signature with Red Hat's keys, pull the release images and, from OpenShift 4.21 only, check their sigstore signatures (not active on 4.18 to 4.20), install approved operators. Each step names its caller, the Red Hat host it reaches and the controls on the way.

Step 2 is the only human action

The cluster admin picks the target with oc adm upgrade. No egress: the Cluster Version Operator does the rest.

Step 7: application pods

Admitted only with allowed images (C8); no proxy settings (C2), no route out (C1). Any other host or registry is blocked at the proxy or refused at admission.
