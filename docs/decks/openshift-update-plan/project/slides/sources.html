Every number in the problem, fixes and road slides was measured on 2026-10-05 from Red Hat's public endpoints: the product life cycle API for support dates, the quay.io tag API for release images, api.openshift.com for the update graph, mirror.openshift.com release.txt for the component image counts, and the security data API for CVEs, each counted once in the month of its first 4.18 fix. The documentation quotes come from the openshift-docs source on GitHub. The industry figures are from Help Net Security and the Cloud Security Alliance; nothing measured here ties a specific OpenShift fix to AI discovery. The commands to repeat each measurement are in PROBLEM-STATEMENT.md.
