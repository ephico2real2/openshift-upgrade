The automation is the same with either registry product: the mirror registry for Red Hat OpenShift, the trimmed-down Quay we run today, or enterprise Red Hat Quay. Red Hat discourages using one single-host mirror registry for several clusters and asks for highly available mirror registries. If each production registry serves several clusters, a highly available registry is the fallback's registry product. The fallback applies only if the change to the proxy approach is not approved.
