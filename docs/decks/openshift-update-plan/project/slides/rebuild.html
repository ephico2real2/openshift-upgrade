Red Hat documents mirror-registry upgrade only from 1.3 to 2.x, migrating PostgreSQL to SQLite. Ours are older than October 2023, so somewhere from 1.0 to 1.3.x; only a 1.3 has a documented path. A fresh install on new RHEL 9 hosts, filled again by oc-mirror v2, is the simpler and safer path.
